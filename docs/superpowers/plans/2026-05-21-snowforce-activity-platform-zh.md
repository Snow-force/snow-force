# SnowForce 活动平台实施计划

> **给代理执行者：** 需要使用 `superpowers:subagent-driven-development`
> 或 `superpowers:executing-plans` 按任务执行。本计划使用复选框步骤追踪进度。

**目标：** 构建一个中英双语 SnowForce 活动运营站，支持公开活动浏览、站内报名、
往期活动回顾、工作人员后台和轻量邮箱会员档案。

**架构：** 使用一个 Next.js TypeScript 应用承载公开页面、会员页面和后台页面。
报名领域逻辑保持在服务端并具备类型约束，使活动状态校验、可配置字段校验、
持久化和通知触发可以复用。使用 Supabase 作为数据库、认证和存储的集成基础；
在生产凭据尚未接入时，使用本地种子数据或回退数据保持脚手架可运行。

**技术栈：** Next.js App Router、React、TypeScript、Tailwind CSS、Supabase、
Zod、Vitest 或仓库选定的单元测试方案，以及可用 Playwright 验证的公开路由。

---

## 文件职责

- 应用外壳与公开路由：`src/app`、`src/components/site`、`src/components/events`。
- 领域类型与校验：`src/lib/events`、`src/lib/registrations`、`src/lib/members`。
- 基础设施适配层：`src/lib/supabase`、`src/lib/email`、`supabase/migrations`。
- 工作人员后台：`src/app/admin`、`src/components/admin`。
- 测试：使用脚手架选定的 `src/**/*.test.ts` 或仓库测试约定。

## 验收覆盖

- 公开访客可以发现当前活动并浏览 SnowForce 往期回顾。
- 访客报名留在站内，并正确处理活动状态、字段校验、同意项、确认结果和通知失败。
- 邮箱会员可以维护可复用资料并查看报名历史。
- 工作人员可以在统一后台管理首版内容与报名运营。
- 应用结构支持后续加入支付、候补名单、会员权益和更丰富分析，而不需要替换活动与报名领域逻辑。
