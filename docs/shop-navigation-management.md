# 商城分类与导航管理

更新：2026-10-08（Pacific）。本轮代码已在本地实现；线上后台的新展示组件和促销接口尚未发布。最新发布与支付缺项见 [本轮验收](shop-navigation-readiness-20261008.md)。

## 导航数据来源

| 前台栏目 | Medusa 管理入口 | 展示规则 |
| --- | --- | --- |
| FEATURED | Products → Collections → 商城展示 | 选择 FEATURED；填写展示顺序、中文名及 HTTPS 展示图片。首页精选横幅优先使用有图片的精选集合。 |
| MEN、WOMEN、KIDS、SKI & SNOWBOARD、ACCESSORIES | Products → Categories | 创建公开、启用的分类，设置父分类和顺序；顶级分类的“商城展示”可指定导航栏目。子分类跟随父分类。 |
| BRANDS | 商品详情 → 商城展示 → Brand | 品牌来自已发布商品的品牌字段，自动生成品牌目录和品牌商品页。统一品牌拼写，避免重复品牌。 |
| SALE | Collections → 商城展示、Promotions、原生价格 | 选择 SALE 的集合、当前有效且关联集合的促销，以及实际有可购买规格降价的商品。促销资格和最终金额由购物车核验。 |

英文名称使用 Medusa 原生分类名称、集合标题及商品标题。中文分类和集合名在“商城展示”填写；留空时使用英文。商品的中文资料沿用现有商品内容。商品图片、规格、库存、售价和上架状态仍在原生商品编辑器管理。

## 添加分类或子分类

1. 在 Categories 创建分类，填写唯一 Handle、名称及描述，设置 Active，关闭 Internal。
2. 子分类选择已有父分类。父分类也必须公开且启用；前台不会绕过隐藏父分类展示其后代。
3. 顶级分类在“商城展示”选择栏目。`men`、`women`、`kids`、`ski-snowboard`、`accessories` 自动对应同名栏目；其他新顶级分类默认进入 SKI & SNOWBOARD，可在后台调整。
4. 在商品原生 Categories 字段关联分类。商品可关联多个分类；父分类页包含其后代关联的商品，每件只出现一次。
5. 发布商品并填写对应 USD 价格与库存。重新加载商城即可看到改动，无需改代码、重新构建或新增页面文件。

分类页地址为 `/shop/categories/<handle>`。修改 Handle 会改变链接，日常改名尽量保留 Handle。英文、中文名称与导航图片均由后台数据生成。空分类显示新品准备中的状态；后台连接失败则明确提示暂时无法加载。

## 管理精选、品牌与优惠

集合页地址为 `/shop/collections/<handle>`。集合默认进入 FEATURED；“商城展示”可改为 SALE 或从导航隐藏。隐藏会取消对应集合列表页，但不替代商品下架或其他访问权限。每个商品的原生 Collection 字段决定集合归属。

线上已有 `sale-clearance`（Sale & Clearance）。发布后台展示组件后，应将该集合的栏目明确选为 SALE；系统不会仅凭标题猜测促销资格。现有其他集合和 `bags-backpacks` 分类会保留。

品牌页地址为 `/shop/brands/<brand>`。品牌统一在商品展示组件填写。仅有草稿商品的品牌不会出现在公开品牌目录；未填写品牌的商品不会被自动归为 SnowForce。

集合的 Public promotion code 可关联 Promotions 中已有的 code。仅主动关联的公开促销码会展示；系统检查启用状态、活动有效期、全局使用次数和预算。顾客、商品、数量等促销条件由 Medusa 购物车最终检查，集合关联本身不保证每件商品都享受折扣。降价标签来自实际可购买规格的原价与当前价格，不从集合名或促销码生成虚构折扣。

## 首次发布与旧数据迁移

先发布 commerce 后台，确认 `/store/snowforce/promotions` 正常返回，再发布 storefront。前台同时读取分类、集合和促销；新版前台不能先于该接口发布。

在配置正确的 commerce 环境中运行一次 `npm run setup:catalog-taxonomy`。脚本使用 Medusa 原生工作流建立五个分类根及原旧分类对应的子分类，只给尚无原生分类关联、且有明确旧分类字段的商品添加关联。已有原生分类和商品关联保留；不会推断男/女归属、改价、改库存或发布商品。冲突的父分类或可见性会停止迁移供人工复核；中断后可重复运行。

脚本尚未对生产数据库执行。MEN、WOMEN 等根分类可先为空，由经营者按实际商品归类。之后新增分类全部使用 Medusa，不依赖脚本内的首次迁移清单。

展示字段保存会检查并发修改，冲突时要求重新加载。保存结果未知时，重试复用原内容，避免覆盖其他管理员的修改。图片必须使用公开 HTTPS URL。
