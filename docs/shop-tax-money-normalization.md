# 优惠分币与配送金额写回

更新：2026-10-02。已实现受保护的原生购物车金额归一化接口和 SQL 事务。它只处理报价前的金额表示，不创建计税报价、应用税行或启动付款。

## 实际行为

`POST /store/snowforce/checkout/:id/normalize` 只接受空对象。Medusa customer 认证和本人购物车检查在接口边界执行；服务自身再次检查身份和 ID。浏览器不能指定售价、优惠、运费、分配方向、许可或税码。

服务从原生购物车读取商品/优惠、实际配送价格和区域，再核对已审核商品分类、已启用经营配置、真实仓库及当前 Stripe 设置。计划读取不生成可用于账本的报价输入。调用者在归一化完成后必须重新读取严格报价来源，不能把原来的半美分购物车直接发送给计税引擎。

两个锁与现有结账使用相同的键：snowforce-checkout:cart ID 和原生 cart ID。事务锁定 cart、地址、商品行、优惠、配送和当前支付关联/集合/会话；在写入前复核归属、币种、region、完成状态、源数据和私有审核事实。已有任何支付会话、支付/订单、授权或资金的集合均拒绝。Stripe 读取在 SQL 事务外。

百分比优惠用确定性的最大余数方法分配整美分，保留原优惠 ID、promotion_id、metadata 和其他上下文。物理 amount 与 raw_amount 同时更新；运费按优惠后未含税商品金额及后台当前规则计算。金额变化会清除旧报价引用，其他购物车 metadata 保留。写入失败、条件不匹配或锁到期，整笔事务回滚。

例如 US$100 商品减 US$0.005，最终优惠为 US$0.01、商品 US$99.99、运费 US$9.95；不能继续按旧的浮点总额判定包邮。两条 US$0.005 优惠合计 US$0.01，分配后不会变成 US$0.02。重复请求读取已精确金额，不再次写入。

金额改变时，已验证无支付会话、授权、支付或资金的空集合关联可以退役，保留原生 payment_collection 完整记录。即使金额已精确，但空集合还使用旧金额，也会解除关联；这条分支不改变报价引用或金额，也不废弃尚未改变输入的税务请求。后续结账建立正确金额的新集合。任何有支付会话的集合都不能走这个分支。

存在未解决税务请求时不修改报价金额，保留原操作供恢复。当前接口响应仅包含 changed、更新行数、是否退役空集合、商品/运费美分和重新审核要求；不返回顾客地址、后台审核信息、支付密钥或原始错误。

## 验证范围

- 使用安装版本的 decorateCartTotals 覆盖半美分、多个优惠分配、US$100 门槛、重试、条件写入、失败回滚、事务入口编辑、过期锁、账户/ID/公开开关和接口输入边界。
- 实际 snowforce_commerce 角色和验证 CA 的 TLS 下，原生表的金额/raw_amount 写入、两类空集合退役、失败/锁到期回滚及重复请求均通过；原生数学函数重新读取实际 SQL 行后得到准确金额。Store metadata 未变、原集合完整字段未变，最终所有测试记录回滚。
- 本阶段实际 Medusa Query 接受 49 个来源字段；后续加入 credit_lines.id 后 50 字段亦已核验，见 [税费应用](shop-tax-quote-application.md)。正向 SQL 验证注入隔离经营审核、Stripe 和锁替身，并用事务内 SQL 加载及真实数学函数生成购物车；不是实际顾客认证、原生 Query 正向读取、真实计税或购买端到端验收。
- 实际 Stripe 仍为测试模式、设置 pending、登记 0，确认开关关闭。没有新表、迁移、正式政策/商品发布、永久测试记录、Stripe POST 或付款。

证据为 `output/shop-tax-normalization-database-rollback.json`、接口 HTTP 记录和同前缀测试/覆盖率/构建日志。具体结果见 [验收记录](shop-verification.md)。

## 接下来如何使用

前台报价流程还没有自动调用这个接口。已实现 [私有报价生产组件](shop-tax-quote-production.md) 和 [原子税费应用](shop-tax-quote-application.md)。调用者应先归一化并严格重新读源，再按持久操作发起 Calculation，最后应用仍匹配的报价。归一化接口不代替最终税务应用事务。

报价前归一化仍拒绝运费优惠、含税标价、礼品卡、自定义/政府费用行。已应用政府费用的有效私有报价可核对复用；过期或需编辑的购物车仍须安全清理后重新归一化，这个生命周期未完成。顾客入口及实际请求验收、成交和退款税账、部分退货财务适配、生产环境和交易演练仍未完成，见 [上线清单](shop-launch-status.md)。
